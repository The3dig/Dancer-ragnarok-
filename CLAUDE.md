# Reino Quebrado Online (MMO do Kravenox)

Projeto pessoal do Rone. As regras gerais do universo ficam no repositório
`The3dig/kravenox` (o livro é o cânone; mudanças de rumo vão para
`decisoes.md`).

## Idioma

**Regra: falar com o Rone só em português.** Vale para TODA mensagem no chat:
avisos curtos durante o trabalho ("agora vou testar…"), resultados de teste,
perguntas, explicações e o resumo final. Nenhuma frase em inglês, nem as
curtinhas do meio do trabalho. Código, comentários, nomes de arquivo e commits
também em português.

## O jogo é todo on-line

- Servidor: `servidor/` (Cloudflare, `kravenox-mmo.kravenox.workers.dev`).
- Para publicar o servidor, ver `servidor/LEIAME.md`.
- Novidade importante para os jogadores entra na lista `NOVIDADES` de
  `3d/avisos.js`, com um id novo. O aviso de uso de internet fica sempre
  no topo.
